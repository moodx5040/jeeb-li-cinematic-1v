طريقة التشغيل:
- افتح index.html في المتصفح.
- الأفضل رفع المجلد كما هو إلى استضافة HTTPS لأن تحديد الموقع يحتاج إذن المتصفح وHTTPS أو localhost.
- النماذج تتحقق من الحقول ثم تفتح WhatsApp برسالة جاهزة إلى رقم الدعم 966571664509. المستخدم يراجع الرسالة ويضغط إرسال بنفسه.
- تحديد الموقع يعمل بعد منح إذن الموقع. عند الرفض يمكنك إدخال رابط خرائط Google يدويًا.
- لا يوجد backend أو قاعدة بيانات أو نظام دفع/تتبع حي؛ هذا Front-end يعمل محليًا ويرسل الطلب عبر WhatsApp.
